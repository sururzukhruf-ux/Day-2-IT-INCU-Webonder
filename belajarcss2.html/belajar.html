Lorem Ipsum (yang mungkin Anda maksud dengan "lorem inpus") adalah teks tiruan atau teks sementara (placeholder) yang menjadi standar di industri desain grafis, percetakan, dan pembuatan website.

Properti Dasar dalam CSS Property adalah atribut yang digunakan untuk mengatur tampilan elemen HTML. Setiap property harus diberi value agar bisa berfungsi.

1. Warna (Color & Background) Digunakan untuk mengubah warna teks, latar belakang, dan elemen.  color → warna teks
 background-color → warna latar belakang
 opacity → tingkat transparansi
 background-image → menambahkan gambar sebagai latar belakang
 background → singkatan untuk berbagai properti background

2. Teks (Text Properties) Mengatur tampilan teks.
 text-align → perataan teks (left, right, center, justify)
 text-decoration → garis dekorasi (underline, overline, line-through, none)
 text-transform → mengubah huruf (uppercase, lowercase, capitalize)
 line-height → jarak antar baris
 letter-spacing → jarak antar huruf
 word-spacing → jarak antar kata
 text-shadow → bayangan teks

3. Font (Jenis & Ukuran Huruf) Mengatur jenis dan gaya huruf.
 font-family → jenis font (contoh: Arial, Times New Roman)
 font-size → ukuran huruf (px, em, rem, %)
 font-weight → ketebalan (normal, bold, 100–900)
 font-style → gaya font (normal, italic, oblique)

4. Box Model (Layout & Ruang) Setiap elemen dalam HTML dianggap sebagai kotak yang terdiri dari:
 margin → jarak luar elemen
 padding → jarak dalam (antara konten dan border)
 border → garis tepi elemen
 width & height → ukuran elemen

5. Border & Outline
 border → mengatur garis di sekitar elemen (tebal, jenis garis, warna)
 border-radius → membuat sudut membulat
 outline → mirip border, tapi tidak memengaruhi ukuran box

6. Background Selain warna, kita bisa menambahkan efek latar:
 background-image → gambar latar belakang
 background-repeat → mengatur pengulangan gambar
 background-size → mengatur ukuran gambar
 background-position → posisi gambar
